전기신문 오피스 1.0.4는 큰 스프레드시트를 스크롤할 때 반복되던 셀 읽기와 화면 갱신을 줄이고, 업데이트 알림과 Windows 기본 앱 등록을 추가한 버전입니다.

## 새로 들어간 것
- 새 버전 알림. 설정 → 프로그램 정보에서 끄거나 직접 업데이트를 확인할 수 있습니다.
- Windows 기본 앱 목록 등록. 기본 앱 선택은 Windows 설정에서 직접 합니다.

## 고친 것
- 스크롤할 때 이미 읽은 범위를 반복해서 지우고 다시 채우던 처리를 줄였습니다.
- 빠른 스크롤 중 읽기 요청이 쌓이지 않도록 마지막 위치를 우선 처리합니다.
- 다른 문서를 열 때 남던 파란 점선을 정리합니다.
- 홈 로고의 배지 겹침과 제목 표시줄 간격을 고치고, 영어 Office 표기를 적용했습니다.
- 설치판은 파일을 직접 풀어 설치합니다. 대용량 DOC 변환기와 탐색기 미리보기 보조 프로그램은 포함하지 않습니다.

## 확인 범위
자동 검사는 설치·업데이트·시작 화면, 주요 동작과 파일 무결성을 확인합니다. 실제 문서 편집의 체감 속도는 PC와 문서에 따라 추가 확인이 필요합니다.

## 설치
- 1.0.3 사용자: Update 파일을 실행하고 기존 Electimes Office.exe가 있는 폴더를 선택합니다. 앱의 설정 → 프로그램 정보에서도 업데이트할 수 있습니다.
- 새 설치 또는 이전 버전: Setup 파일을 사용합니다.
- 설치 전에 문서를 저장하고 오피스를 종료해 주세요. 사용자 문서와 설정은 유지합니다.
