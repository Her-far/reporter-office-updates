DOC 문서를 한 번 열고 닫으면 다시 열리지 않던 문제를 수정했습니다.

## 고친 것

- 닫은 DOC 문서를 드래그하거나 최근 문서에서 다시 열 수 있습니다.
- 이미 열린 문서는 새로 변환하지 않고 해당 탭이나 창을 표시합니다.
- 닫힌 문서의 임시 변환 파일을 정리합니다. DOC 원본은 그대로 유지됩니다.

## 설치

- 현재 1.0.3 또는 1.0.4: 설정 → 프로그램 정보 → 업데이트 확인, 또는 Update EXE를 실행하세요.
- 처음 설치하거나 더 오래된 버전: Setup EXE를 실행하세요.
- 업데이트 전에는 작업 중인 문서를 저장하고 오피스를 종료해 주세요.
