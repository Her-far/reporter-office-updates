전기신문 Office 1.0.12 — 인쇄 설정창 호환성 개선 · 누적 업데이트

업데이트 용량 수정
- 1.0.6~1.0.11: ElectimesOffice-Update-1.0.12-Cumulative-x64.exe를 사용합니다. 중간 버전을 건너뛰어도 필요한 이전 수정 파일이 모두 포함됩니다.
- 1.0.11에서만 사용하는 기존 소형 패치도 그대로 제공됩니다.
- 새 설치 또는 1.0.6보다 이전 버전: ElectimesOffice-Setup-1.0.12-x64.exe를 사용합니다.
- 기존에 286.3MB가 표시됐다면 설정 → 정보에서 업데이트 확인을 다시 눌러 주세요. 자동 업데이트 배포 주소는 같습니다.
- 이미 1.0.12가 설치됐다면 다시 설치할 필요가 없습니다. 앱 내용은 그대로이며 업데이트 배포 파일의 적용 범위를 넓혔습니다.

인쇄 수정 사항
- 인쇄 기본 설정창에 Windows의 기존 프로그램용 화면 배율 처리를 적용합니다. 창과 내부 항목이 서로 다른 배율로 표시되는 문제를 줄이고 설정을 닫으면 원래 배율로 복원합니다.
- HWP 인쇄 시 오피스에 연결된 임시 창을 표시하고 초점을 맞춰 설정창이 뒤로 숨지 않도록 했습니다.
- 1.0.11의 HWP 붙여넣기·빈 줄 간격 및 이전 문서·패널 수정 사항을 유지합니다.

검증 범위
- 1.0.6~1.0.11의 실제 Windows 설치본 각각에 누적 업데이트를 설치하고, 전체 설치판과의 파일 일치 및 정상 실행을 검사했습니다.
- 사용자 파일과 로컬 OAuth 설정 이전용 백업 보존, 반복 설치, 지원하지 않는 버전 거부 및 기존 앱의 업데이트 파일 선택을 검사했습니다.
- Windows 기본 인쇄 대화상자 열기·취소, 인쇄창 DPI 상태와 복원, 화면 배율별 PDF 용지 크기를 검사했습니다. 사용자 PC의 실제 복합기 드라이버와 종이 출력은 원격 빌드 환경에서 검증할 수 없었습니다.
