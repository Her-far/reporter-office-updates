전기신문 Office 1.0.7 — 업무패널 정식 통합

- AI·간편 메일·기존 웹메일·구글 캘린더·메모/체크리스트 패널을 정식판에서 사용할 수 있습니다.
- 첨부파일 기본 저장 폴더를 선택하고, 별도 하위 폴더 없이 바로 저장합니다. 같은 이름은 번호를 붙여 보존합니다.
- 탭을 바꿔도 패널 너비·확장 상태를 유지합니다.
- 좁은 창에서는 상단 메뉴를 좌우로 이동합니다.
- 문서 탭 아래의 별도 자동저장 줄을 없애고, 스위치를 메뉴 줄 오른쪽에 배치해 편집 공간을 넓혔습니다.
- 1.0.5의 DOC 닫기 후 재열기 수정과 1.0.6의 업데이트 다운로드 수정이 포함됩니다.
- 같은 Windows 사용자로 처음 실행하면, 정식판 업무패널 설정이 없는 경우에만 테스트판의 메모·설정·암호화된 간편 메일/구글 연결을 복사합니다. 원본은 유지됩니다. 기존 웹메일은 다시 로그인이 필요할 수 있습니다.

설치 전 문서를 저장하고 프로그램을 종료하세요. Setup 파일 하나로 새 설치와 기존 정식판 업데이트를 모두 지원합니다. 기존 문서·설정은 유지됩니다.
1.0.5 이하에서 프로그램 내 다운로드가 실패하면 Setup 파일을 직접 실행하세요.

줄바꿈 표시 이상과 Windows 한자 후보창 취소 문제는 아직 해결되지 않았습니다.
실제 계정 연결은 이전 테스트판에서 사용자 확인을 받았습니다. 자동 검증은 실제 회사 계정에 로그인하지 않습니다.

구글 앱 비밀값은 공개 설치파일에서 분리했습니다. 기존 PC의 연결 설정은 로컬에서 암호화해 유지하며, 새 PC는 회사에서 제공한 설정 파일을 한 번 가져와야 합니다.
