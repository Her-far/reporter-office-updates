전기신문 Office 1.0.7

AI·메일·캘린더·메모 업무패널이 정식판에 통합되었습니다.
- 간편 메일: 네이버웍스 IMAP 및 외부 앱 비밀번호로 최초 연결합니다. 같은 Windows 사용자에서는 연결 정보를 암호화하여 기억합니다.
- 메일 ⋯ 또는 첨부파일 아래 ‘저장 위치 변경’에서 기본 폴더를 선택합니다. 폴더에 바로 저장하고 중복 이름에는 번호를 붙입니다.
- AI·메일·캘린더·메모를 전환해도 패널 너비를 유지합니다.
- 상단 메뉴가 잘리면 좌우 화살표·마우스 휠로 이동합니다.
- 닫은 DOC를 최근 문서·드래그로 다시 여는 1.0.5 수정과 업데이트 다운로드 오류에 대한 1.0.6 수정을 유지합니다.

이전 테스트판에서 사용했다면
- 같은 Windows 사용자로 정식판을 처음 실행할 때, 정식판의 업무패널 설정이 아직 없으면 테스트판의 메모·설정·암호화한 간편 메일/구글 연결 정보를 복사합니다.
- 테스트판과 기존 정식판의 파일·설정을 덮어쓰거나 삭제하지 않습니다.
- 기존 웹메일 화면의 로그인은 다시 필요할 수 있습니다.
- 다른 Windows 계정이나 PC에서는 계정을 다시 연결하세요.

업데이트 전에 문서를 저장하고 오피스를 종료하세요.
이번 버전은 기존 정식판 설치 폴더와 업데이트 주소를 그대로 사용합니다.
줄바꿈 표시 이상과 Windows 한자 후보창 취소 문제는 아직 해결되지 않았습니다.

구글 캘린더 연결 설정
- 공개 설치파일에는 구글 앱 비밀값을 포함하지 않습니다.
- 기존 암호화된 설정은 유지합니다. 기존 정식판에 포함됐거나 기본 경로의 테스트판에 남아 있는 설정은 이 PC에서만 암호화해 가져옵니다.
- 새 PC에서는 회사에서 제공한 구글 연결 설정 JSON을 캘린더의 ‘연결 설정 파일 가져오기’로 한 번 선택하세요. 이후 구글 계정으로 로그인합니다.
- 설정 파일은 공개 저장소나 공개 링크에 올리지 마세요.
