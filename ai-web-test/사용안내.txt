전기신문 Office — AI 웹 채팅 테스트판 (1.0.12-aiweb.1)

1. ‘전기신문 Office AI 웹 테스트’를 실행하고 AI 탭을 엽니다.
2. ‘문서 도우미’와 ‘AI 웹 채팅’을 전환할 수 있습니다.
3. 웹 채팅에서 ChatGPT / Claude / Gemini를 선택한 뒤 본인 계정으로 로그인하세요.
4. 본인 계정의 무료 또는 유료 구독 범위로 이용합니다. 웹 채팅에는 별도 API 키가 필요하지 않으며 오피스가 AI API 요금을 추가로 청구하지 않습니다. 사용 한도는 각 서비스에서 정합니다.
5. 문서에서 Ctrl+C로 복사한 뒤 AI 입력칸에 Ctrl+V로 붙여넣으세요. 답변도 복사해서 문서에 붙여넣을 수 있습니다. ‘AI에 붙여넣기’와 ‘문서에 붙여넣기’ 버튼은 마지막 입력 위치에 서식 없는 텍스트로 붙여넣습니다. 전송은 직접 눌러주세요.
6. 메일·메모나 다른 문서로 이동했다 돌아와도 서비스별 웹 화면은 유지됩니다. 로그인은 이 테스트판 안에서 별도로 저장됩니다.
7. 확대 후에는 상단 ‘패널로 돌아가기’ 또는 Esc를 사용하세요.
8. 내장 화면에서 로그인 제한이나 브라우저 확인이 표시되면 ‘브라우저에서 열기’를 누르세요. Google 로그인은 기본 브라우저를 사용합니다. 외부 브라우저 로그인은 내장 화면과 자동으로 공유되지 않습니다.

정식판과 별도 설치 폴더, 설정, 로그인 저장소를 사용합니다. 정식판의 문서 연결과 자동 업데이트를 바꾸지 않습니다. 테스트판은 자동 업데이트하지 않습니다. 기존 문서를 열고 저장하면 그 문서 자체는 변경되므로 시험 편집에는 사본을 사용하세요.
웹 채팅에는 사용자가 직접 붙여넣거나 첨부한 내용만 전달합니다. 웹 페이지는 오피스의 문서 편집 명령이나 내부 연결 정보에 접근할 수 없습니다.
