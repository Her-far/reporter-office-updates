AI 탭에서 **문서 도우미 / AI 웹 채팅**을 전환하는 별도 Windows 테스트판입니다.

- ChatGPT·Claude·Gemini 웹사이트 선택
- 본인 계정의 구독·무료 이용 한도로 웹 채팅 이용: Office의 별도 API 호출 없음
- 서비스 전환과 문서 이동 시 대화 화면 유지
- 복사한 질문을 AI에 붙여넣기, 복사한 답변을 문서에 붙여넣기
- 홈/문서에서 패널 확대 후 돌아가기 버튼과 Esc 지원
- 정식판과 설치·설정·로그인 분리, 정식판 자동 업데이트 영향 없음

**정식판 1.0.12가 설치되어 있으면 Compact-Setup.exe를 권장합니다.** 공통 파일은 PC 안에서 복사하므로 다시 내려받지 않습니다. 정식판이 없거나 기준 파일 검사에 실패하면 Full-Setup.exe를 사용하세요.

서비스 계정의 실제 로그인은 별도 확인이 필요합니다. Google 로그인 등 내장 브라우저에서 제한되는 경우 ‘브라우저에서 열기’를 사용하세요. 외부 브라우저의 로그인은 내장 화면과 공유되지 않습니다. 문서 내용은 자동으로 웹 AI에 전달되지 않습니다.

테스트판에서 원본 문서를 저장하면 그 문서가 바뀌므로 기능 검증에는 사본을 사용하세요.
