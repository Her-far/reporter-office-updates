**AI 웹 브라우저 테스트판 3**입니다. 실제 ChatGPT·Claude·Gemini 웹사이트를 Chrome 또는 Edge로 사용합니다.

- AI → AI 웹 브라우저 → 서비스/브라우저 선택 → 열기
- 브라우저의 원래 로그인, 대화 목록, 첨부·검색 등 웹 기능을 사용합니다.
- 실제 독립 브라우저 창이 오피스 패널 위치를 따라 움직입니다. 주소창을 유지하며 창 분리도 가능합니다.
- 오피스 이동, 좌우 배치, 확대/복원, 패널 전환, 최소화에 맞춰 표시됩니다.
- 웹에서 답변 복사 → 문서에 붙여넣기. 문서 내용은 자동 전송하지 않습니다.
- CLI 프로그램을 사용하거나 추가 다운로드하지 않습니다.

정식판 **1.0.12가 있으면 Compact-Setup.exe**, 없거나 설치 검증에 실패하면 Full-Setup.exe를 사용하세요. 이전 AI 웹 테스트판을 종료한 후 설치합니다. 정식판 자동 업데이트에는 배포하지 않습니다.

실제 Chrome/Edge 창과 설치 격리를 Windows에서 검사합니다. **개인 계정 로그인과 실제 구독 답변은 사용자 PC에서 확인이 필요합니다.**
