AI 탭의 **구독 대화**를 시험하는 두 번째 독립 테스트판입니다.

- ChatGPT: 공식 계정 연결 후 패널 안에서 대화. 외부 브라우저 로그인 결과가 패널로 돌아옵니다.
- Claude: 공식 Claude Code를 패널 안에서 실행하고 본인 구독으로 로그인합니다.
- Gemini: 공식 Google Antigravity를 패널 안에서 실행하고 지원되는 Google 계정으로 로그인합니다.
- 기존 웹사이트 대화 목록과는 별도입니다. 문서 내용은 자동 전달하지 않습니다.
- Claude·Gemini는 처음 한 번 공식 실행 프로그램을 다운로드합니다. 기존 설치가 있으면 재사용합니다.

정식판 1.0.12가 있으면 **Compact-Setup.exe**를 사용하세요. 없으면 Full-Setup.exe를 사용하세요. 정식판의 설치/설정/자동 업데이트 경로는 변경하지 않습니다.

Windows 합성 OAuth/응답, 실제 공식 실행 파일의 초기 화면, ConPTY 입력, HWP 붙여넣기, 재시작 및 설치 격리를 검증합니다. **실제 개인 계정의 로그인과 구독 응답은 아직 별도 확인이 필요합니다.** API 계정/별도 결제를 직접 선택하면 해당 요금이 적용될 수 있습니다.
