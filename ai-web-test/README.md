# 전기신문 Office AI 웹 브라우저 테스트판 3

AI 탭에서 **문서 도우미 / AI 웹 브라우저**를 선택합니다. ChatGPT·Claude·Gemini의 원래 웹사이트를 PC에 설치된 Chrome 또는 Edge에서 엽니다. 테스트판 2의 CLI/구독 채팅 화면은 사용하지 않습니다.

## 사용

1. 이전 AI 웹 테스트판을 종료하고 테스트판 3을 설치합니다. 정식판 1.0.12가 있으면 Compact, 없거나 파일 검증에 실패하면 Full 설치판을 사용합니다.
2. AI → AI 웹 브라우저 → 서비스와 브라우저 선택 → 열기를 누릅니다.
3. 웹사이트에서 평소처럼 로그인하고 질문합니다. 선택한 브라우저의 프로필을 사용하므로, 해당 프로필에 로그인돼 있으면 그 계정과 대화 목록을 이용합니다. 다른 프로필은 브라우저의 프로필 메뉴에서 선택합니다.
4. 오피스의 패널 확대/복원 버튼으로 넓게 볼 수 있습니다. **창 분리**를 누르면 일반 브라우저 창으로 사용합니다.
5. 문서에서 원하는 부분을 복사한 뒤 웹 입력칸에 붙여넣습니다. 답변은 웹사이트에서 복사한 뒤 **문서에 붙여넣기**로 넣습니다.

## 브라우저 연결 방식과 한계

- 실제 Chrome/Edge의 **독립된 최상위 창**을 패널 위치와 크기에 맞춥니다. Electron 안에 웹사이트를 삽입한 웹뷰나 CLI 화면이 아닙니다. 주소창, 탭, 프로필과 웹사이트 기능을 유지합니다.
- 오피스 이동/크기/패널 방향을 따라갑니다. 다른 패널이나 서비스로 전환하면 해당 연결 창을 숨기고 복귀하면 다시 표시합니다. 오피스 종료 시 브라우저를 일반 창으로 돌려놓습니다. 브라우저 프로세스를 종료하지 않습니다.
- 브라우저 선택 후 새로 연 창만 연결합니다. 기존 개인 브라우저 창의 위치를 바꾸지 않습니다. 동시에 여러 새 창이 열려 구별할 수 없으면 자동 연결을 중단합니다.
- 로그인은 웹사이트와 브라우저가 처리합니다. Office는 쿠키/프로필/비밀번호를 읽거나 복사하지 않으며, 디버깅 포트·보안 해제·브라우저 위장·자동 질문 전송을 사용하지 않습니다.
- Windows의 가상 데스크톱, 브라우저 프로필 선택 화면이나 특수한 창 관리 프로그램에서는 창 위치 연결에 차이가 있을 수 있습니다. 창 분리로 일반 브라우저 사용이 가능합니다.
- 브라우저의 프로필 선택 때문에 연결된 창이 닫히면 프로필 선택을 완료한 후 다시 열어 주세요.
- 개인 계정의 로그인과 구독 기능은 각 서비스/조직 정책을 따릅니다. 실제 계정으로 로그인한 최종 확인은 사용자 PC에서 필요합니다.

## 설치

정식판의 설치 폴더, 설정, 문서 연결, 자동 업데이트를 바꾸지 않습니다. 기존 AI 웹 테스트판의 별도 프로필을 사용합니다. CLI 프로그램을 추가 설치하지 않으며 Chrome/Edge가 이미 설치돼 있어야 합니다.

## 검증

Windows에서 실제 설치된 브라우저의 새 창 생성, 좌우 패널 배치, 위치/확대/복원, 패널 전환/최소화, 창 분리, HWP 답변 붙여넣기와 독립 설치를 검사합니다. 개인 계정 로그인과 유료 답변은 자동 테스트하지 않습니다. 검증 결과는 릴리스의 `ui-windows.json`, `install-windows.json`에 게시합니다.
