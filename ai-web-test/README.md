# 전기신문 Office AI 웹 채팅 테스트판

정식판 1.0.12를 기반으로 AI 탭 안에서 **문서 도우미 / AI 웹 채팅**을 전환하는 Windows 테스트판입니다. 웹 모드에서는 ChatGPT, Claude, Gemini 웹사이트를 선택합니다. 해당 서비스에 로그인한 계정의 구독·무료 이용 한도가 적용되며, 이 모드는 Office에서 API를 호출하지 않습니다.

선택한 문서나 메일을 자동으로 전달하지 않습니다. 사용자가 내용을 복사하고 붙여넣는 방식입니다. 웹 답변을 복사한 뒤 ‘문서에 붙여넣기’를 누르면 마지막 문서 커서 위치에 일반 텍스트로 붙여넣습니다.

## 설치와 분리

- `Compact-Setup.exe`: 설치된 정식판 **1.0.12**의 공통 파일을 검사한 후 별도 폴더에 복사합니다. 검사에 실패하면 전체 테스트 설치파일을 사용합니다.
- `Full-Setup.exe`: 정식판 설치 여부와 관계없이 테스트판 전체를 설치합니다.
- 설치 폴더: `%LOCALAPPDATA%\Programs\ElectimesOffice-AIWeb-Test`
- 설정·로그인 폴더: `%APPDATA%\ElectimesOffice-AIWeb-Test`
- 정식판의 업데이트 주소, 설정, 파일 연결과 설치 등록을 변경하지 않습니다. 테스트판에는 자동 업데이트가 없습니다.
- 테스트판에서도 같은 원본 문서를 편집하고 저장하면 해당 파일이 변경됩니다. 기능을 확인할 때는 문서 사본을 사용하세요.

## 웹 서비스 로그인 범위

서비스별 저장 공간을 분리해 로그인과 탭의 대화 초안을 유지합니다. 실제 계정의 로그인 성공 여부는 자동 검증에 포함되지 않습니다. 웹 서비스의 로그인·보안 정책에 따라 내장 화면 이용이 제한될 수 있습니다.

Google 로그인은 내장 브라우저에서 진행하지 않습니다. 이 경우 **브라우저에서 열기**를 선택해 기본 브라우저에서 해당 서비스를 이용하세요. 외부 브라우저 로그인은 Office 내장 화면으로 옮겨지지 않습니다. 사용자 에이전트 위장, 보안 정책 우회, 외부 브라우저 쿠키 복사를 사용하지 않습니다.

## 재현 가능한 검증

`.github/workflows/ai-web-test.yml`에서 공개 정식판 1.0.12의 SHA-256을 확인하고 독립된 테스트판을 만듭니다. Windows에서 가상 웹 페이지로 전환, 초안 유지, 명시적 복사·붙여넣기, 홈/문서 확대 복귀, 서비스별 세션 분리를 검증합니다. 실제 서비스는 로그인하지 않은 첫 화면만 확인합니다.

설치 테스트는 소형·전체 설치 후 파일 해시, 잘못된 기준 버전 거부, 반복 설치, 정식판 보존, 별도 등록, 동시 실행과 제거 시 사용자 파일 보존을 확인합니다. `electimes-latest.json`과 `main` 브랜치에는 변경하지 않습니다.

원본 Apache-2.0 라이선스와 구성 요소별 고지를 유지합니다. 테스트판 변경 파일은 이 디렉터리에 있습니다.
