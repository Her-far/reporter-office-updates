전기신문 Office 1.0.8 — 구글 계정 간편 연결

- 새 PC에서도 별도 OAuth 발급·설정 파일 가져오기 없이 구글 계정 연결을 시작합니다.
- 기본 브라우저에서 사용할 구글 계정을 선택하고 캘린더 권한을 허용합니다.
- 구글 앱 비밀값은 공개 설치파일에 포함하지 않고 인증 서버에만 보관합니다. 서버는 인증 코드 교환·연결 갱신만 처리하며, 일정은 PC와 Google 사이에서 직접 전송됩니다.
- 기존 PC의 암호화된 계정 연결과 설정은 유지합니다.
- DOC 재열기, 공통 패널 크기, 첨부파일 저장 폴더, 상단 메뉴 이동, 자동저장 줄 제거 등 1.0.7의 개선을 유지합니다.

Google 프로젝트의 테스트 모드 해제와 앱 검증은 별도 관리자 설정입니다. 이번 배포가 Google의 게시 상태를 변경하지는 않습니다. 테스트 상태에서는 등록된 계정만 연결할 수 있고 권한 만료 제한이 적용됩니다.

설치 전 문서를 저장하고 프로그램을 종료하세요. 1.0.5 이하에서 프로그램 내 다운로드가 실패하면 Setup 파일을 직접 실행하세요.
줄바꿈 표시 이상과 Windows 한자 후보창 취소 문제는 아직 해결되지 않았습니다.
자동 검사는 실제 개인 계정에 로그인하지 않습니다.
