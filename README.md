# 기자오피스 Windows 업데이트

기자오피스 설치 파일과 자동 업데이트 정보를 제공하는 배포 전용 저장소입니다.

## 최초 연결 (0.12.5.35)

1. 기자오피스의 **설정 → 정보 → 업데이트 배포 주소 설정**을 펼칩니다.
2. 다음 주소를 붙여넣고 **주소 저장**을 누릅니다.

```text
https://raw.githubusercontent.com/Her-far/reporter-office-updates/main/reporter-latest.json
```

3. **업데이트 확인**을 누릅니다. 현재 공개 버전은 **0.12.5.35**입니다.

이후 새 릴리스가 게시되면 같은 주소에서 확인할 수 있습니다. 새 버전의 **다운로드 및 업데이트** 버튼으로 설치하며, 저장하지 않은 문서는 기존 저장 확인 절차를 거칩니다.

## 설치 파일

- [공개 릴리스](https://github.com/Her-far/reporter-office-updates/releases/latest)
- `ReporterOffice-Update-0.12.5.35.exe`: 0.12.5.34용 누적 패치, 설치 취소 오류 수정판.
- `ReporterOffice-FullUpdate-0.12.5.35.exe`: 더 오래된 설치본용 전체 누적 업데이트. 기존 기자오피스 설치 폴더에 적용하며 새 PC용 신규 설치 파일은 아닙니다.

업데이트 기능이 있는 설치본은 지원 범위에 따라 소형 패치 또는 전체 누적 업데이트를 선택합니다. 중간 버전을 순서대로 설치할 필요는 없습니다. 업데이트 기능이 없는 구버전은 전체 업데이트를 한 번 직접 적용하고 위 주소를 저장하세요.

다운로드 파일의 크기와 SHA-256은 `reporter-latest.json`에 기록됩니다. 배포 파일을 먼저 업로드하고 검증한 다음 이 정보를 갱신합니다.

이 저장소에는 개발 프로젝트 소스나 사용자 문서를 게시하지 않습니다. GitHub가 자동 표시하는 Source code ZIP/TAR는 이 배포 저장소의 내용입니다. 포함 구성 요소의 라이선스와 고지는 설치 파일에 유지됩니다.
