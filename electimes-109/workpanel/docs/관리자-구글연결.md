# 구글 연결 관리자 설정

1. Google Cloud 프로젝트 `electimes-office-test`에서 **Google Auth Platform → 대상(Audience)**을 엽니다.
2. 회사 직원들이 각자의 구글 계정으로 연결할 경우 외부(External) 앱의 게시 상태를 **프로덕션(In production)**으로 전환합니다.
3. Google이 요구하는 브랜드·권한 검증을 확인합니다. 프로덕션 전환만으로 미검증 경고와 사용자 한도가 모두 없어지는 것은 아닙니다.
4. 신규 사용자 계정으로 실제 연결과 재시작 후 동기화를 확인합니다. 테스트 모드에서 발급한 연결은 전환 후 다시 연결하는 편이 좋습니다.

일반 사용자는 OAuth 자격 증명을 발급받거나 JSON 파일을 가져오지 않습니다. OAuth JSON 가져오기는 별도 등록을 사용하는 관리자를 위한 호환 옵션입니다.

인증 서비스: https://electimes-calendar-auth.idealnacre6.chatgpt.site
인증 서비스는 Google 권한 게시 상태를 변경하지 않습니다. 현재 자동 검증은 새 프로필 UI, PKCE, 취소, 인증 서버와 Google 토큰 엔드포인트까지 확인하며 실제 개인 계정의 로그인은 포함하지 않습니다.
